# SDK consumer acceptance

The standalone consumer owns context, lifecycle and export destinations. It imports only the ASHCore and ASHPatternSystem public products, with Apple native modules.

The command-line runner exercises all 512 state round trips, eight malformed external representations, all seven operational classes, explicit context requirements, canonical reachability and averaging, correction and both replacement fallback policies, complete planning and deterministic in-memory emission, and refusal of an incomplete plan. The composed and dual-product routes also exercise session isolation, malformed bootstrap, policy resolution, fallback exhaustion, failed and contained restrictions, confirmed breach, and every public session entry after safe halt. A frozen public snapshot is retained as caller-owned evidence in addition to the SDK's paired JSON/Markdown support export.

For a downloaded aggregate, run `verify/verify-consumer.sh --sdk /absolute/extracted/ASH-Apple-SDK-version --output /absolute/empty/evidence --simulators`. The harness requires macOS, Xcode with iPhone and iPad simulator runtimes, Python 3, and ripgrep. It builds three isolated Release consumers, rejects zero or duplicate observations, runs the sample on an iPhone and an iPad simulator, and cross-builds the sample for a generic iOS device. Set `ASH_PRODUCER_ROOT` to the producer checkout to deny its filesystem access during command-line binary build and runtime. Network access is denied for those command-line cases.

The sample project references `../SDK`; create an `SDK` symlink beside its `app` directory pointing to the extracted binary package. It imports the public products through that package, owns its lifecycle and explicit operational context, and exports to its private Documents directory. The simulator runner clears only this disposable sample's installation before each run, then retains its fresh report, exports, exact destination identifier, and screenshot. A generic device build is compile/link evidence; physical-device runtime is separately identified when it has not been exercised.

Source acquisition is verified from an immutable Git revision and the exact release tag by `tools/sdk/verify-source-consumer.sh` in the source repository. `tools/sdk/compare-consumers.py` compares the checked cases and deterministic public planning, emission, recovery and averaging results against binary acquisition. Qualification records identify the source commit, SDK bytes, toolchain, destination, case counts and unexecuted environments. This example document describes the checks; an actual acceptance claim requires their successful evidence records.
