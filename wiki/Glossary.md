# Glossary

| Term | Meaning |
|---|---|
| State | Nine-bit structural value 0...511 |
| Realm | Deterministic identity for the full state |
| Orbit | Sixteen states reachable by the fixed codeword translations |
| Context | Explicit validated stable-target and fallback authority |
| Correction | Same-orbit canonical XOR action to selected stable target |
| Replacement fallback | Explicit policy candidate replacement, immediately reassessed |
| Containment | Restricted session mode with preserved evidence |
| SAFE_HALT | Terminal frozen session; host process is not killed |
| Semantic diagnostic ID | SHA256-derived identity of nine canonical semantic fields |
| Occurrence | Root/parent/sequence and metadata separate from semantic ID |
| Support export | Caller-owned bounded immutable JSON/Markdown pair |
| Source qualification | Actual source commands/tests at a recorded revision |
| Binary qualification | Actual archive/interface/symbol/resource and public runtime checks |
| Hardware qualification | Separate owner physical-device execution, pending |
