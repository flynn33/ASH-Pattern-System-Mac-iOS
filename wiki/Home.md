# ASH Apple SDK 1.0.0

The native SDK provides ASHCore and ASHPatternSystem as source Swift packages and two Release dynamic XCFrameworks. Apple marketing/build identity is 1.0.0 / 2; deployment metadata is macOS14/iOS16. Runtime uses Apple modules only.
