# Design roadmap — Apple SDK 1.0.0

The current delivery target is the native source/binary SDK release, with explicit public products, corrected canonical bindings, complete mapped tests, support exports, isolated public consumers and verified publication. [SDK acceptance](sdk-acceptance.md), release manifests and the final external verification record define actual completed gates.

The implementation now includes fixed structural math, validated context assessment, deterministic correction/replacement policies, bounded topology, evidence-aware axioms, complete plans, in-memory emission, canonical diagnostics and actor-owned containment/terminal lifecycle. Root/nested packages and explicit library-evolution Xcode schemes use the same sources. Curated assets exclude test corpora and full authority/producer repositories.

Further deployment qualification remains owner-controlled: physical devices, oldest supported OS/older compiler/Intel runtime, product UI/accessibility, product signing, notarization, App Store/TestFlight and product installation/upgrade/removal. None is relabeled as accepted by the SDK release. Historical completion reports are preserved without rewriting their verdicts.
