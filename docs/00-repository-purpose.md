# Repository purpose

This repository implements the Apple SDK 1.0.0 in native Swift. It owns public-product construction, Apple build/package metadata, support exports, public examples, tests and evidence. Its canonical semantic input is the separately pinned ASH-Pattern-System 1.0.0-rc.3; [authority and conformance](sdk-authority-and-conformance.md) records precedence.

The deliverable is a source package plus two dynamic XCFrameworks and a curated release. Product-specific UI, signing, deployment and physical-hardware approval are distinct phases. The SDK example owns a small verification application, not a shipped product UI. Historical app-readiness reports remain historical. [Current acceptance](sdk-acceptance.md) and final release manifests state actual evidence boundaries.
