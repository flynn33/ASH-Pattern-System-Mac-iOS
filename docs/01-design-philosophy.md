# Design philosophy

Native Apple implementation preserves the fixed F2^9 model and explicit canonical decisions. Swift tools 5.10 defines package syntax; actual qualification uses the recorded Xcode/Swift compiler. Runtime dependencies are Apple modules only.

Structural algebra and operational authority are separate: normalization preserves all 512 states, while context supplies stable targets and fallback evidence. Pure immutable services support explicit construction; an actor owns mutable operational state. Decisions retain explanatory canonical diagnostics. Terminal sessions freeze before return and cannot resume mutation.

Planning produces a complete abstract contract before in-memory descriptor emission. Support collection is caller-owned, bounded, redacted and compiled to the appropriate diagnostic profile. Export publishes one immutable JSON/Markdown pair or reports a typed failure. Neither domain operations nor support code acquires an external service or authority checkout.

Qualification distinguishes source tests, compiled interfaces/binaries, actual host/simulator runtime, downloaded bytes and physical hardware. Missing evidence stays explicit; distribution minima and architecture metadata do not fill runtime gaps.
